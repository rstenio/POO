Com o polimorfismo, mesmo que a classe mãe não conheça a implementação do método, uma vez que eu herdar ele e definir o corpo na classe filha, a instância de qualquer objeto das classes filhas conhecerá ambos os métodos

3.(c) A interface Entregavel foi usada em vez de uma classe abstrata porque o Java não permite herança múltipla. Como ProdutoFisico já faz extends de Produto, o uso de uma interface permite adicionar-lhe características extra, algo impossível se fosse mais uma classe. Numa interface, o estado não pode ser armazenado (os atributos são apenas constantes), enquanto as classes abstratas podem ter variáveis de instância (estado). Além disso, uma classe pode implementar diversas interfaces, mas só pode herdar diretamente de uma única classe abstrata
